# Hotel Management & Revenue Analytics System

A data analytics project for analyzing hotel bookings, revenue, occupancy, customer behavior, and business performance.

## Objectives

- Design a relational hotel database using MySQL
- Perform advanced SQL analysis
- Clean and analyze data using Python and Pandas
- Build business intelligence dashboards using Power BI
- Generate actionable business insights
- Demonstrate an end-to-end data analytics workflow

## Technology Stack

- MySQL
- SQL
- Python
- Pandas
- NumPy
- Power BI
- DAX
- Node.js
- Express.js
- Git
- GitHub
